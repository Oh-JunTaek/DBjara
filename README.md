## 개요 및 개발 목적

* 게임 플레이 자체를 완전히 끊기는 어렵지만, 혼자서 솔로 랭크를 돌릴 때 자제력을 잃고 수면 패턴이 무너지는 사용자를 위한 프로그램입니다.
* 친구들과 함께하는 2인 이상 다인큐는 자유롭게 허용하되, **혼자서 매칭을 돌리는 행위만 감지하여 실시간으로 취소**합니다.
* 사용자가 스스로 설정을 변경하거나 프로그램을 종료하는 것을 막기 위해 **동반자(친구/가족) 스마트폰 기반의 OTP 자물쇠 시스템**을 지원합니다.

## 주요 기능

| 기능 | 설명 | 동작 방식 |
| :--- | :--- | :--- |
| **솔로 플레이 실시간 차단 (기본값: 중)** | 다인큐는 허용하고 1인 솔로 매칭만 차단 | 로비 인원이 1명인 상태에서 매칭 시작 시 실시간으로 매칭 검색을 취소(DELETE API)합니다. |
| **야간 강제 취침 모드 (디비자라 모드)** | 설정된 야간 시간대에 게임 실행 전면 차단 | 밤 11시 ~ 아침 7시(사용자 지정 가능)에 롤이 실행되면 즉시 프로세스를 강제 종료합니다. |
| **동반자 OTP 인증 시스템** | 제3자의 승인 없이는 앱 종료/설정 변경 불가 | 신뢰하는 지인의 스마트폰 OTP 앱에 키를 등록하여, 지인의 6자리 승인 번호가 있어야 잠금이 해제됩니다. |
| **일일 솔로 시간 제한 (하 모드)** | 솔로 플레이 시간을 하루 단위로 제한 | 하루 누적 솔로 플레이 시간이 설정값(예: 1시간)을 초과하면 이후 매칭을 차단합니다. |
| **강제 종료 방지 (Watchdog)** | 작업 관리자 강제 종료 방어 | 백그라운드 감시 프로세스가 상주하여 메인 프로그램이 비정상 종료되면 즉시 재실행합니다. |
| **윈도우 시작 시 자동 실행** | 부팅 시 백그라운드 상주 | 윈도우 레지스트리에 등록되어 PC를 켜면 자동으로 감시를 시작합니다. |
| **Riot ID 전적 검증** | 외부/PC방 플레이 감지 | 소환사 계정을 등록해두면 공식 Match API로 최근 솔로 랭크 플레이 이력을 교차 검증합니다. |
| **자동 업데이트 확인** | 깃허브 최신 릴리즈 감지 | 프로그램 시작 시 새 버전 출시 여부를 확인하여 알림을 제공합니다. |

## 라이엇 게임즈 운영정책 준수 안내

* DBjara는 인게임 메모리를 변조하거나 불공정한 이점을 제공하는 불법 소프트웨어가 아닙니다.
* OP.GG, Blitz.gg 등과 동일하게 라이엇 공식 LCU(League Client Update) 로컬 API의 표준 엔드포인트를 호출하여 로비 인원을 확인하고 매칭 취소를 요청합니다.
* 라이엇 서드파티 개발자 정책을 준수하므로 계정 제재(밴) 위험 없이 사용하실 수 있습니다.

## 동반자 OTP 설정 가이드

본인의 의지만으로 통제가 어려울 때 친구에게 통제 권한을 부여하는 방법입니다.

1. DBjara 트레이 아이콘 우클릭 후 **'설정 열기'**를 선택합니다.
2. **'동반자 OTP 자물쇠 활성화'**를 체크한 뒤 **'동반자 등록 QR / 비밀키 보기'** 버튼을 누릅니다.
3. 친구의 스마트폰에서 OTP 앱(Google Authenticator 등)을 열고 QR 코드를 스캔하여 등록합니다.
4. 등록 완료 후에는 친구의 스마트폰 화면에 뜨는 6자리 번호를 입력해야만 설정을 변경하거나 프로그램을 종료할 수 있습니다.

## 실행 및 사용 방법

### 1. 로컬 환경 실행
1. 저장소 코드를 내려받습니다.
2. 폴더 내 `run.bat`을 실행합니다.
3. 화면 우측 하단 시스템 트레이에 DBjara 아이콘이 상주하면 감시가 시작됩니다.

### 2. 단일 실행 파일 (.exe) 빌드
1. `build_exe.bat`을 실행하면 파이썬 설치 없이 독립적으로 동작하는 `dist/DBjara.exe`가 생성됩니다.
2. 비개발자 사용자는 생성된 `DBjara.exe` 파일 하나만 실행하여 사용할 수 있습니다.
