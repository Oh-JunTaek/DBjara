## ✨ 사용자 중심 핵심 기능

| 기능 | 설명 | 작동 방식 |
| :--- | :--- | :--- |
| **🚫 솔로 플레이 실시간 차단**<br>*(중 모드 - 기본값)* | 친구와의 다인큐는 마음껏 즐기되,<br>**혼자서 큐를 돌리는 행위만 정확히 차단**합니다. | 로비 인원이 1명인 상태에서 매칭을 누르면<br>매칭 검색을 **실시간으로 즉시 자동 취소**시킵니다. |
| **🌙 야간 강제 취침 모드**<br>*(디비자라 모드)* | 밤 11시 ~ 아침 7시(시간 조절 가능)에는<br>**게임 실행 자체를 전면 차단**합니다. | 야간 시간대에 롤이 실행되면 안내창을 띄우고<br>**프로세스를 즉시 강제 종료**합니다. |
| **🔒 동반자 OTP 자물쇠**<br>*(소셜 자제력 시스템)* | 내가 스스로 설정을 바꾸거나<br>프로그램을 끄지 못하도록 **친구 폰에 자물쇠**를 겁니다. | 친구 스마트폰의 Google OTP 앱에 키를 등록하고,<br>**친구의 6자리 승인 번호**가 있어야만 끌 수 있습니다. |
| **⏰ 일일 솔로 시간 제한**<br>*(하 모드)* | 솔로 플레이를 완전히 막지 않고<br>하루 정해진 시간(예: 1시간)만 허용합니다. | 하루 누적 솔로 시간이 초과되면<br>이후 솔로 매칭을 자동으로 차단합니다. |
| **🛡️ 강제 종료 방지**<br>*(Watchdog)* | 작업 관리자에서 프로세스를 꺼버리는<br>순간적인 꼼수를 방어합니다. | 백그라운드 감시자가 상주하여<br>프로그램이 꺼지면 **1초 만에 즉시 부활**시킵니다. |
| **⚙️ 윈도우 부팅 시 자동 실행** | 컴퓨터를 켜자마자 백그라운드에 상주합니다. | 윈도우 시작 프로그램에 등록되어 매번 켤 필요가 없습니다. |

## 🛡️ 라이엇 게임즈 제재(밴) 위험이 없나요?

> [!NOTE]
> **100% 안전합니다.**
> * **DBjara**는 메모리를 변조하거나 인게임 플레이에 개입하는 불법 헬퍼/핵 프로그램이 아닙니다.
> * OP.GG, Blitz.gg 등과 동일하게 라이엇 공식 **LCU (League Client Update) 로컬 API**를 사용하여 로비 인원수를 확인하고 매칭 취소 요청만 보냅니다.
> * 라이엇의 서드파티 개발자 정책을 완벽하게 준수하므로 계정 정지나 밴 걱정 없이 사용하실 수 있습니다.

## 📱 동반자 OTP 연동 3단계 가이드 (1분 완성)

내가 자제력이 약해질 때를 대비하여 친구에게 통제권을 부여하는 방법입니다:

```text
[1단계] 'DBjara' 트레이 아이콘 우클릭 ➔ '⚙️ 설정 열기'
[2단계] '동반자 OTP 자물쇠 활성화' 체크 ➔ '📱 동반자 등록 QR / 비밀키 보기' 클릭
[3단계] 친구의 스마트폰 'Google Authenticator' 앱으로 QR 코드를 스캔하면 등록 완료!
```
* 이제부터 설정을 바꾸거나 프로그램을 종료하려면 **친구의 스마트폰 화면에 뜨는 6자리 번호**를 입력해야 합니다.

## 💻 사용 방법 (설치 & 실행)

### 방법 1. 원클릭 실행 (현재 버전)
1. 본 저장소의 코드를 다운로드합니다.
2. [`run.bat`](file:///d:/dev/Documents/dbjara/run.bat)을 더블 클릭합니다.
3. 화면 오른쪽 아래 작업 표시줄(시스템 트레이)에 **🌙 달 모양 아이콘**이 나타나면 감시가 시작된 것입니다!

### 방법 2. 일반 사용자용 무설치 단일 파일 (.exe) 배포 예정
* 파이썬 설치 없이 더블 클릭 한 번으로 실행되는 `DBjara.exe`가 [Releases](https://github.com/Oh-JunTaek/DBjara/releases) 탭에 업로드될 예정입니다.

## ❓ 자주 묻는 질문 (FAQ)

**Q. 친구들이랑 2인 듀오나 5인 자랭/칼바람을 할 때는 어떻게 되나요?**  
A. 로비 인원이 2명 이상이면 **DBjara**가 전혀 개입하지 않으므로 평소처럼 자유롭게 플레이하실 수 있습니다!

**Q. 야간 시간대를 제 생활 패턴에 맞게 바꾸고 싶어요.**  
A. 설정 창에서 '차단 시작 시간'과 '종료 시간'을 자유롭게 변경(예: 01:00 ~ 08:00)하실 수 있습니다.

**Q. 프로그램을 끄고 싶은데 친구가 연락이 안 돼요!**  
A. 바로 그것이 이 프로그램의 목적입니다! 친구가 답장할 때까지 롤을 켜지 마시고 일찍 주무시는 것을 권장합니다. 😴
