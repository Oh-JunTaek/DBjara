# 🌙 디비자라 (dbjara) - LoL Solo Blocker

> **"친구와의 롤은 즐겁게, 혼자만의 밤샘 솔랭은 강력하게 통제합니다."**

리그 오브 레전드(League of Legends)의 솔로 플레이 과몰입 및 야간 수면 패턴 파괴를 방지하기 위해 제작된 백그라운드 상시 통제 프로그램입니다.

---

## 🌟 핵심 기능

1. **솔로 랭크 / 싱글 플레이 감지 및 매칭 즉시 취소 (중 모드 - 기본값)**
   - Riot LCU (League Client Update) API를 통해 실시간으로 로비 인원수를 감시합니다.
   - **혼자서 큐를 돌릴 때 (1인)**: 매칭 검색을 실시간으로 취소(`DELETE` 요청)하여 솔로 큐 진행을 차단합니다.
   - **친구와 함께할 때 (2인 이상 다인큐)**: 아무런 제재 없이 자유롭게 플레이 가능합니다.

2. **🌙 야간 시간대 강제 차단 (디비자라 모드)**
   - 설정된 야간 시간대(기본: 밤 11시 ~ 아침 7시)에는 동반자 여부와 관계없이 롤 클라이언트 실행 즉시 강제 종료합니다.

3. **통제 강도 3단계 설정**
   - **상 (High)**: 게임 실행 자체 차단 (실행 즉시 강제 종료).
   - **중 (Medium - 권장)**: 1인 솔로 플레이만 차단 (2인 이상 큐 허용).
   - **하 (Low)**: 하루 최대 솔로 허용 시간(예: 2시간) 설정 및 초과 시 차단.

4. **🔒 동반자 OTP 인증 시스템 (소셜 자제력 자물쇠)**
   - 신뢰하는 친구/가족의 스마트폰(Google Authenticator 등)에 OTP 키를 등록합니다.
   - 사용자는 스스로 설정을 변경하거나 프로그램을 끌 수 없으며, 친구에게 연락해 6자리 번호를 받아 입력해야만 해제됩니다.
   - *선택 기능으로 사용자가 원할 때 켜고 끌 수 있습니다.*

5. **이중 감시 프로세스 (Watchdog)**
   - 작업 관리자(`taskmgr.exe`)에서 강제 종료를 시도해도 백그라운드 Watchdog 프로세스가 즉시 프로그램을 다시 부활시킵니다.

6. **부팅 시 자동 실행**
   - 윈도우 시작 프로그램에 등록하여 PC 부팅 시 자동으로 백그라운드에서 실행됩니다.

---

## 🚀 실행 방법

* **프로그램 실행**: 폴더 내 [`run.bat`](file:///d:/dev/Documents/dbjara/run.bat)을 더블 클릭합니다.
* **설정 창 열기**: 화면 우측 하단 작업 표시줄의 시스템 트레이에서 **달/별 모양 아이콘**을 우클릭하고 **'⚙️ 설정 열기'**를 클릭합니다.

---

## 📁 파일 구조

* `app.py`: 메인 백그라운드 감시 루프 및 시스템 트레이 아이콘 서비스
* `gui.py`: 통제 강도 설정 및 동반자 OTP 관리 화면 (Tkinter 다크 테마)
* `lcu.py`: 라이엇 클라이언트 LCU API 연동 및 매칭 제어 모듈
* `totp.py`: RFC 6238 표준 TOTP 생성 및 검증 엔진
* `config.py` & `config.json`: 사용자 설정 및 누적 시간 보관
* `watchdog.py`: 강제 종료 방지 상호 감시 프로세스
* `run.bat`: 백그라운드 원클릭 실행 스크립트
